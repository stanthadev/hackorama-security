# Hackorama Security Labs

A responsive React website starter for Hackorama Security Labs, built with Vite and React.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Project structure
```text
src/
  components/   Shared navigation and footer
  pages/        Home, About, services, projects, insights and contact
  styles/       Global responsive styling
  App.jsx       Routes
  main.jsx      React entry point
```

## Before publishing
1. Replace the sample contact email and social links with official company details.
2. Add only real projects, qualifications and services you can currently deliver.
3. Review the privacy notice and add one if you introduce forms or analytics.
4. Check business-name and trademark availability before formal registration.

## Hosting
This is a static frontend and can be deployed to a compatible static host. Check the host's current plan terms, especially commercial-use restrictions, before publishing a business website.
